# 演示视频分镜稿（3–5 分钟）

> 录制前通读 `docs/demo-guide.md` 并完成其中「演示前准备」清单。
> 每个分镜标注了时长、画面与口播要点；口播可自由发挥，数字勿改。

## 分镜 1：开场（0:00–0:20）

- **画面**：README 首屏滚动到「当前证据与边界」。
- **口播**：一句话定位 + 指出我们把"哪些已验证、哪些没做"写在最显眼处。

## 分镜 2：架构与差异（0:20–0:50）

- **画面**：README 系统架构 Mermaid 图（渲染后），切「与同类工具的差异」表。
- **口播**：三模式分工；与聊天壳、黑盒编排的两三点差异；强调从零实现、
  4 个运行时依赖。

## 分镜 3：离线热身（0:50–1:20）

- **画面**：终端运行 `python main.py --demo`，逐步展示思考→行动→观察。
- **口播**：模型只发指令，Python 工具执行；不需要 API Key，零成本。

## 分镜 4：黄金路径——自动路由（1:20–1:50）

- **画面**：工作台（`start.bat` 打开 127.0.0.1:8765），选 Auto 模式，
  输入"检索 ReAct 论文并总结它的核心思想与局限"，特写路由决策面板。
- **口播**：注意路由给出的模式选择和**理由**——这是可解释路由，不是黑盒。

## 分镜 5：黄金路径——轨迹与产物（1:50–2:40）

- **画面**：实时轨迹日志滚动；完成后打开产物区（论文、笔记）。
- **口播**：检索→下载→分段阅读→记笔记；长论文按页分段，不塞爆上下文。

## 分镜 6：黄金路径——指标（2:40–3:00）

- **画面**：本次运行的指标面板（耗时、LLM 调用、工具调用、token）。
- **口播**：执行级指标是实验台的核心：每次运行都能回答"花了多少成本"。

## 分镜 7：历史证据与同源回放（3:00–3:50）

- **画面**：工作台“已保存案例”选择器回放公开案例；再打开
  `docs/case-study.md` 第 3 节和 `evals/case_results/react-method-evidence-v1/runs.jsonl` 局部。
- **口播**：三模式真实对比；重点讲 ReAct 步数耗尽的失败被完整保留——
  回放和实时运行走同一结果展示，评分仍标为作者初步自评，正式结论未产出。

## 分镜 8：安装、测试与治理（3:50–4:20）

- **画面**：终端 `scholaragent --demo` 与 `pytest -q` 输出（130+ passed）；GitHub
  仓库页展示 `.github/` 目录、CI 状态、ROADMAP.md。
- **口播**：源码和安装入口都能离线演示；130+ 项离线测试一条命令复验；发布纪律
  写进测试；季度路线图把比赛线与研究线分开。

## 分镜 9：收尾（4:20–4:40）

- **画面**：回到 README 首屏。
- **口播**：定位复述 + 邀请复验："所有数字都能用仓库里的命令重新跑出来。"

## 录制纪律

1. 每个分镜一条素材，方便剪辑与重录；总时长控制在 4 分半以内。
2. 出现的每个数字必须与本稿或 README 一致；说不准的数字不说。
3. 在线运行片段若录制失败，用案例证据包画面替代，口播注明"历史证据"。
4. 终端字体调大（建议 16pt+），窗口背景干净，避免泄漏无关文件路径。
