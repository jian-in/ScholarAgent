# 参赛报名简介

> 结构按评审维度组织：技术创新 30% / 场景落地 30% / 开源治理 20% /
> 长期发展 20%。所有数字的来源在文末注明，均可从仓库复验。

## 一句话介绍

ScholarAgent 是面向科研文献调研的**透明智能体实验台**：从零实现轻量 Agent
框架（不依赖 LangChain），能自动在 ReAct / Plan / Team 三种执行模式间路由，
全过程保留轨迹、执行级指标与产物，失败也如实记录。

## 技术创新（30%）

1. **从零实现的轻量 Agent 循环**：约 200 行的「思考→行动→观察」核心，
   含步数保险丝、工具白名单、坏参数容错，运行时仅 4 个依赖。
2. **可解释三模式路由**：版本化特征 `task-features-v1` + 规则基线
   `rule-router-v1` + 可安全回退的离线学习路由；路由决策输出特征、理由与
   策略版本，规则路由在固定 36 题上与复杂度标签 100% 一致（零模型调用复验）。
3. **执行级指标与产物追踪**：每次运行记录真实耗时、LLM/工具调用与 token
   （缺失记 `None`，绝不伪造），并归档论文、笔记、记忆产物。
4. **失败可见工程化**：真实案例中 ReAct 模式步数耗尽未产出回答被完整保留；
   策略文件损坏时打印原因并回退规则路由。

## 场景落地（30%）

- 解决科研人员「检索 → 下载 → 精读 → 记笔记 → 汇总」的真实调研流程，
  支持长论文分段阅读（33 页 ReAct 论文 8 次分段读完）。
- 主证据为可公开复验的真实案例（arXiv:2210.03629，三模式对比）：
  Plan 模式 0.945 分（含逐字引文与页号），Team 0.885 分，ReAct 失败运行
  完整保留——输入、轨迹、产物、评分、复现命令全链路可追溯。
- 五分钟演示黄金路径见 `docs/demo-guide.md`，含网络故障离线兜底。

## 开源治理（20%）

- MIT 许可证；CONTRIBUTING / SECURITY / CODE_OF_CONDUCT / MAINTAINERS /
  CHANGELOG 齐备；Issue / PR 模板与双系统 CI（GitHub Actions）。
- 发布纪律写入测试：`tests/test_public_release.py` 自动拦截私人信息、
  本地运行产物与未经证实的表述。

## 长期发展（20%）

- 季度路线图（`docs/ROADMAP.md`）：比赛线（打包发布、插件接口、任务集
  扩展）与研究线（完整校准、学习路由实验、留出集对比）分开承诺。
- 社区可领取任务（good first issue）清单与维护边界明确。

## 诚实边界（主动披露）

- 29/54 条真实校准观测仅用于成本诊断；**学习路由的正式对比结论尚未产出**。
- 案例评分为作者初步自评，独立人工评分进行中。
- 规则路由 36/36 表示与预设复杂度标签一致，不代表回答质量。
