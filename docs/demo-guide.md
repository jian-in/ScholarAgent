# 五分钟演示指南

本指南固化评审现场的黄金演示路径：**输入任务 → 自动路由（查看理由）→
执行轨迹 → 论文/笔记产物 → 质量与成本指标 → 评分**。全程约 5 分钟，
每一步都有离线兜底，不依赖私人数据。

## 演示前准备（前一天完成）

- [ ] `.\.venv\Scripts\python.exe -m pytest -q` 全绿（当前 130+ 项）
- [ ] `.env` 中 API Key 可用，或本机 Ollama 已运行（`main.py` 会自动探测）
- [ ] 打开三个窗口备用：本 README、本地工作台（`start.bat`）、
      [`docs/case-study.md`](case-study.md)
- [ ] 预读一遍本指南，记住兜底切换点

## 演示流程

### 0:00–0:30 开场（讲什么）

一句话定位：

> ScholarAgent 是面向科研文献调研的透明智能体实验台：自动选择
> ReAct / Plan / Team 三种执行模式，全过程保留轨迹、指标与产物，
> 失败也如实记录。

指向 README 首屏「当前证据与边界」：先说清楚哪些已验证、哪些未完成
（学习路由正式结论尚未产出），建立可信度。

### 0:30–1:00 离线热身（零成本，展示 Agent 循环）

```powershell
.venv\Scripts\python main.py --demo
```

不需要 API Key。展示「思考→行动→观察」循环与工具白名单：模型只生成
工具名和参数，搜索、计算、记忆都由 Python 工具执行，错误以文字回传纠错。

### 1:00–3:30 黄金路径（在线运行，Auto 模式）

工作台方式（推荐，可视化）：

```powershell
.\start.bat        # 打开 http://127.0.0.1:8765
```

选择 **Auto** 模式，输入固定演示任务：

```text
检索 ReAct 论文并总结它的核心思想与局限
```

按界面顺序讲解：

1. **自动路由**：Auto 面板显示所选模式、策略版本与**路由理由**
   （特征命中了什么，为什么选这个模式）——这是与黑盒编排的核心差异。
2. **执行轨迹**：逐步展示搜索 → 下载 → 分段阅读 → 存笔记的实时日志。
3. **产物**：任务完成后查看收集到的论文与笔记。
4. **指标**：查看本次运行的耗时、LLM 调用次数、工具调用与 token。

CLI 等价命令（备用）：

```powershell
.venv\Scripts\python main.py --auto "检索 ReAct 论文并总结它的核心思想与局限"
```

> 注意：现场**不要**演示 33 页全文精读类长任务（黄金路径控制在 2.5 分钟内）；
> 长任务的三模式真实对比用下一节的历史证据展示。

### 3:30–4:30 历史证据与评分（离线重放）

打开 [`docs/case-study.md`](case-study.md)，展示三模式对比表：

- ReAct 模式步数耗尽、未产出回答——**失败被完整保留**，这是实验台的诚实边界；
- Plan 模式 0.945 分，含逐字引文与页号；
- Team 模式 0.885 分，综述式含后续工作对比。

原始数据可现场打开 `evals/case_results/react-method-evidence-v1/runs.jsonl`
与 `scores.jsonl` 核验（评分与运行分离存放）。

### 4:30–5:00 收尾（讲什么）

- 复验入口：130+ 离线测试 + `pytest -q` 一条命令；规则路由 36 题一致性
  零模型调用即可复验（README「成本感知自适应路由」节的命令）。
- 治理与长期发展：CI、贡献指南、路线图（`docs/ROADMAP.md`）——
  比赛线与研究线分开，未完成实验不包装成结论。

## 兜底切换点

| 故障 | 切换动作 |
|---|---|
| API Key 失效 / 云端超时 | 改用 Ollama 本地模型，或退回 `--demo` 离线演示 |
| arXiv 网络不可达 | 说明 `arxiv_search` 自动兜底 OpenAlex；如仍失败，直接进入历史证据环节 |
| 工作台异常 | 用 CLI `--auto` 等价命令演示同一任务 |
| 时间不足 | 跳过离线热身，直接黄金路径 + 历史证据 |

## 演示纪律

1. 在线运行与已保存证据包必须口头区分（“这是刚才的实时运行”vs
   “这是 8 月 26 日的保存证据”）。
2. 遇到失败不重试美化：如实说明失败形态，并指出它被记录在哪。
3. 只引用可复验的数字；“尚未产出正式成本对比结论”要主动说。
