# 资料缺口调研说明

工作台中的“补齐四项缺口”是一个受控的 Plan 任务模板，解决的是“把多个方向列在
建议里，却没有真正逐一启动”的问题。它不在后台自动开跑，必须由用户确认后点击
“开始调研”，因为四个方向会显著增加检索、阅读时间和模型调用次数。

## 四个固定方向

1. 推理能力：CoT、ToT 等推理分解、搜索、验证和修正机制；
2. Agent 工具使用：工具选择、参数生成、反馈利用和错误恢复；
3. 2024-2025 年进展：最新代表论文和系统性综述的覆盖范围、分类与结论；
4. 推理效率：量化、推测解码、服务系统、硬件与显存/速度/质量权衡。

任务会被确定性拆成四个独立步骤，而不是再把“全部方向”交给模型自由规划。工作台提供
两种深度：

- 快速模式：每个方向至少检索 3 篇候选，只看标题和摘要，不下载 PDF，适合先确定
  哪些论文值得继续投入时间；结果中的实验和局限只允许写摘要明确支持的内容。
- 深度模式：每个方向至少检索 3 篇，并至少精读 1 篇到全文读完，适合形成可用于论文
  写作的页码级证据。

两种模式都要求记录论文核心卡片：

```text
论文标题 / arXiv 编号 / 年份
核心问题
核心方法或机制
实验设置与关键结论
局限性
证据页码或摘要
```

四个步骤完成后，汇总器还要输出四方向对比、项目启示和剩余缺口。若最终回答缺少方向
或核心字段，系统会自动进行一次结构修订；修订失败时会把缺失项明确写出来，不把任务
标成完整。

## 使用方式

在网页工作台点击“快速补齐四项缺口”或“深度补齐四项缺口”，检查自动填入的任务文本
和 `Plan` 模式，再点击“开始调研”。运行日志会出现“执行 1/4”到“执行 4/4”，结果
元信息会标记 `gap-survey` 工作流。若只想查一个方向，不要使用该快捷入口，直接输入
单方向问题，这样可以进一步节省调用和阅读成本。

## 诚实边界

四路启动表示四个方向都进入了执行流程，不表示每个方向一定检索成功或已经获得高质量
证据。arXiv、OpenAlex、下载、OCR 或本地模型失败时，结果必须保留失败状态和资料缺口；
论文核心只能来自实际检索/阅读内容，不能由模型凭常识补齐。
