# 独立人工评分表模板

本表用于案例和路由实验的独立评分。评分者不参与模型运行，不根据作者自评调整分数；
每个分数必须在 0 到 1 之间，并填写证据位置或证据缺口。

## 评分元数据

| 字段 | 待填写 |
|---|---|
| experiment_id |  |
| run_id |  |
| scorer_type | `independent` |
| scorer_id | 仅用匿名编号，不写姓名或联系方式 |
| scoring_method | 例如：盲评、按四项 rubric 独立评分 |
| scored_at |  |

## 分数

| 维度 | 分数 0–1 | 证据位置/缺口说明 |
|---|---:|---|
| task_completion |  |  |
| factual_correctness |  |  |
| citation_validity |  |  |
| output_completeness |  |  |

质量加权口径固定为：`0.40×task_completion + 0.30×factual_correctness +
0.20×citation_validity + 0.10×output_completeness`。未填写的分数不是零分，
而是“未评分”；请不要把作者评分改名为独立评分。
